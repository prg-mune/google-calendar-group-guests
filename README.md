# Google Calendar Group Guests

Google Calendar の予定作成/編集画面で、事前登録したメンバーグループをまとめてゲスト欄に追加する Chrome 拡張です。v1.0.3 では、左ペイン上でグループの追加/編集/削除とゲスト追加ができます。

## できること

- Google Calendar 左側のゲスト欄付近に、マイカレンダー風のゲストグループ一覧を表示する
- 左側の「ゲストグループ」見出し横の `+` からグループを追加する
- 左側のグループ行からゲスト追加/編集/削除を行う
- Chrome 拡張のポップアップでもゲストグループを作成/編集/削除する
- グループ名とメールアドレス一覧を登録/削除する
- Google Calendar の予定作成/編集画面で、選択したグループの全員をゲスト欄へ順番に入力する
- 拡張一覧とツールバー用のアイコンを表示する

## 導入手順

1. Chrome で `chrome://extensions` を開きます。
2. 右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. このフォルダを選択します。
5. Google Calendar を開いているタブを再読み込みします。

## 使い方

1. Google Calendar を開きます。
2. 左側の「ゲストグループ」見出し横の `+` から、グループ名とメールアドレスを登録します。
3. Google Calendar で予定を新規作成、または既存予定を編集します。
4. 左側の「ゲストグループ」で対象グループを押します。
5. 予定のゲスト欄にメールアドレスが入力されたら、Google Calendar 側で予定を保存します。

グループ行にマウスを乗せると、右側に編集/削除ボタンが表示されます。Chrome ツールバーの拡張機能ポップアップからも同じ管理ができます。

## 仕様メモ

- グループ情報は `chrome.storage.sync` に保存します。
- 初回はサンプルグループが入っています。不要なら削除してください。
- Google Calendar の画面DOMを操作するため、Google側のUI変更で調整が必要になる場合があります。
- カレンダーの予定保存までは、追加されたゲストは確定しません。
- 拡張を更新した後は、`chrome://extensions` で拡張機能の更新ボタンを押し、Google Calendar のタブを再読み込みしてください。

## 次に拡張しやすいこと

- 管理者が共通グループを配布する仕組みを追加する
- Google グループのメールアドレス展開に対応する
- 登録済みグループの編集機能を追加する
- Google Calendar のUI変更に強い入力処理へ調整する

## Apps Script 版について

`Code.js` と `appsscript.json` は Google Workspace Add-on 版の試作用ファイルです。Chrome 拡張として使う場合は、`manifest.json`、`popup.html`、`popup.css`、`popup.js`、`content.js`、`content.css` を使います。
